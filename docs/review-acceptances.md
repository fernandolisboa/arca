# Accepted review findings

Medium findings from must-pass reviewers that a change accepts instead of fixing ([REVIEW.md](REVIEW.md#verdicts)). The CI review gate reads this file. A lasting trade-off also goes in an ADR.

Each row applies to one pull request only. The gate matches reviewer, file and category exactly: the reviewer by its agent name (such as `security-reviewer`), the file as the finding names it, and the category from the gate's fixed list (`tooling/scripts/src/review-gate/schema.ts`). Each row needs a reason; the reviewers see new rows in the diff.
