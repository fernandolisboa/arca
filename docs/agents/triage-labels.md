# Triage labels

The skills speak in five canonical triage roles. This repo uses the default label strings.

| Role in mattpocock/skills | Label in this repo | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | The owner or an agent needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent session |
| `ready-for-human` | `ready-for-human` | Needs the owner: a credential, a browser-only click or a product decision |
| `wontfix` | `wontfix` | Will not be actioned |

Category roles use the existing `bug` and `enhancement` labels.
